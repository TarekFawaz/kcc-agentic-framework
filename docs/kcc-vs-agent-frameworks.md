# KCC vs Agent Frameworks

KCC is not trying to replace every agent framework or coding assistant. It is a
workflow and operating-model layer around agentic software delivery.

| Tool category | Typical focus | KCC focus |
|---|---|---|
| Coding assistant | Faster local coding. | Governed idea-to-review workflow. |
| Prompt library | Reusable instructions. | Kernel contracts, gates, traces, and reusable capabilities. |
| Agent framework | Agent execution primitives. | Delivery lifecycle, human gates, evidence, and team-owned cells. |
| Project template | Initial file layout. | Regenerable harness adapters from `.KCC` source of truth. |

KCC can sit beside many tools. It provides the structure for how work should
move, what artifacts should exist, and when humans must approve decisions.
