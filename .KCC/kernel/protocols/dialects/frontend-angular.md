# Frontend Angular Dialect

Use for Angular applications.

## Coding
- Follow Angular workspace conventions, typed components/services, reactive forms where appropriate, and accessible templates.

## Review
- Check component boundaries, state flow, RxJS cleanup, accessibility, responsive layout, and test coverage.

## Bug Fix
- Reproduce in component/service test or browser, patch narrow component/service, run tests.

## Testing
- Unit tests for components/services; e2e or browser checks for critical flows.

## Docs
- README must include Node version, package manager, run/test commands, routes, and build notes.

## Complexity
- low: junior-safe component/style.
- medium: mid-level feature flow.
- high: senior state/routing/integration.
- extra-high: principal-expert design system, performance, or platform work.
