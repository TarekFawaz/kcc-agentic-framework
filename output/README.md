# Generated Output Samples

This folder is reserved for captured examples of generated output when the
public repo needs to show what init/sync produces.

Do not treat this folder as framework source. The source of truth remains:

- `.KCC/kernel/`
- `.KCC/capabilities/`
- `.KCC/tools/`
- root documentation files

Live harness adapter surfaces such as `.claude/`, `.codex/`, `.opencode/`,
`.agents/`, and `ollama/` are generated locally by init/sync and should not be
committed as source.
